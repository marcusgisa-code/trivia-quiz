2. Welche Daten werden verarbeitet?

2.1 Angaben beim Spielstart

Beim Start eines Spiels gibst du freiwillig einen selbst gewählten Namen und deine Postleitzahl (PLZ) an. Diese Angaben dienen ausschließlich dazu, deinen Punktestand einem Bezirk (PLZ) zuzuordnen und in der Highscore-Liste anzuzeigen. Eine Identitätsprüfung findet nicht statt – die Angaben sind frei wählbar.

2.2 Spieldaten (Firebase Firestore)

Punktestände, Anzahl gespielter Runden und die PLZ werden in der Cloud-Datenbank Google Firebase Firestore gespeichert, um die Highscore-Listen anzuzeigen. Google LLC (USA) verarbeitet diese Daten dabei ggf. auch außerhalb der EU; Grundlage hierfür sind die Standardvertragsklauseln der EU-Kommission bzw. das EU-U.S. Data Privacy Framework, sofern Google diesem beigetreten ist. Weitere Informationen: firebase.google.com/support/privacy.

Gespeicherte Felder je nach Spielmodus: Name, PLZ, Ort (aus PLZ abgeleitet), Punktestand, Anzahl Spiele, Zeitstempel sowie eine Liste bereits gespielter Fragen-IDs (damit dir Fragen nicht zu häufig wiederholt werden).

2.3 Ortsname zur PLZ (Zippopotam.us)

Um zu deiner PLZ einen Ortsnamen anzuzeigen, wird die PLZ an den kostenlosen, öffentlichen Dienst Zippopotam.us übermittelt. Es werden dabei keine weiteren personenbezogenen Daten übertragen.

2.4 Fragen-Abruf (Cloudflare Worker)

Die Quizfragen werden über einen eigenen, bei Cloudflare gehosteten Worker ausgeliefert. Dabei werden technisch bedingt IP-Adresse und Standard-Zugriffsdaten von Cloudflare verarbeitet (Server-Log-Daten), jedoch keine von dir eingegebenen personenbezogenen Daten.

2.5 Hosting (GitHub Pages)

Diese Seite wird über GitHub Pages (GitHub, Inc. / Microsoft) ausgeliefert. Beim Aufruf der Seite verarbeitet GitHub automatisch technische Zugriffsdaten (u. a. IP-Adresse, Browsertyp, Zeitpunkt des Zugriffs) in Server-Logs. Näheres: GitHub Privacy Statement.

2.6 Lokale Speicherung im Browser

Einige technische Einstellungen (z. B. ob der Sound stummgeschaltet ist) werden ausschließlich lokal in deinem Browser (localStorage) gespeichert und nicht an einen Server übertragen. Es werden keine Cookies zu Tracking- oder Werbezwecken eingesetzt.

4. Speicherdauer

Spieldaten werden gespeichert, solange das Projekt betrieben wird. Eine automatische Löschung nach einem festen Zeitraum findet derzeit nicht statt. Du kannst jederzeit die Löschung deiner Daten beantragen (siehe Punkt 6).

5. Keine Weitergabe an Dritte zu Werbezwecken

Es findet keine Weitergabe deiner Daten an Dritte zu Werbe- oder Marketingzwecken statt. Die unter Punkt 2 genannten Dienstleister (Google Firebase, Cloudflare, GitHub, Zippopotam.us) werden ausschließlich zum technischen Betrieb dieser Anwendung eingesetzt.
